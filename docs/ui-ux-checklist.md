# LearnSphere UI/UX 개선 종합 체크리스트

- **서비스**: 수준별 로드맵 제공 + 문서 파싱 RAG + 학습 자료·퀴즈 생성 + 학습 도우미 챗봇
- **타겟**: 학습을 어디서부터 시작해야 할지 막막한 개발자
- **핵심 목표**: 사용자 편의 증가, 디자인 요소 고도화
- **작성일**: 2026-07-27 (기준 커밋: `20301e7 style: 원목·종이 테마로 디자인 리뉴얼`)
- **재점검**: 2026-07-27 Phase 13 완료 시점 — 아래 상태 표기는 재점검 결과가 반영된 현재 상태 (하단 "재점검 결과" 참조)

각 항목은 실제 코드베이스 조사 결과를 반영해 **현재 상태**를 함께 표기했다:
✅ 예(충족) / ❌ 아니오(미충족) / ⚠️ 부분 충족. 코드 근거가 있는 항목은 파일 경로를 병기했다.

**폰트 라운드 적용 내역**
- Pretendard·JetBrains Mono를 npm 패키지(`pretendard`, `@fontsource/jetbrains-mono`)로 셀프호스팅 — dynamic subset이라 필요한 서브셋 woff2만 페치, 외부 CDN 요청·preconnect 전부 제거

- `Pretendard Fallback` @font-face 메트릭 오버라이드(size-adjust 99% 등)로 폰트 스왑 리플로우 완화 → `/`·`/login` CLS 0.00x
