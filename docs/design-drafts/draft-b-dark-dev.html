useState로 상태 다루기

컴포넌트가 기억해야 하는 값은 변수 대신 state로 선언합니다. state가 바뀌면 React가 화면을 다시 그립니다.

Counter.jsx
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  // setCount를 호출하면 화면이 다시 그려집니다
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}
QUIZ [2/3]

state를 직접 수정하지 않고 setCount를 사용하는 이유는 무엇인가요?

정답 — React는 setter 호출을 통해서만 변경을 감지하고 리렌더링을 예약하기 때문입니다.
