설계 노트:
- 앰버 정체성 유지를 위해 라이트 accent는 다크 앰버(`#8f5500`)로 낮춰 텍스트·버튼 겸용 AA를 확보 (밝은 `#ffb454`는 흰 배경에서 1.8:1로 사용 불가).
- 코드 블록(`--color-code-bg`)은 라이트에서도 다크를 유지한다(에디터 무드, Prism 다크 테마 재사용). 인라인 코드만 `--color-code-inline-bg` 토큰으로 분리해 라이트에서 밝은 칩으로 교체.
